# v0.1.0-alpha.1

First experimental prerelease of the FNAF 4 Borderless Mod.

Includes borderless 16:9, Escape-to-menu during nights, mouse flashlight/door controls, and experimental FPS unlocking. Extract the two configuration/DLL files beside the original EXE; no launcher is required.

Build verification passed. Earlier borderless output was observed at 1920×1080. The current FPS, Escape, and mouse changes are untested in gameplay. This release is intended for testing, not a claim of stability. Set `UnlockFPS=0` if uncapped drawing causes problems.

Contains mod files only. No original game data is distributed.
